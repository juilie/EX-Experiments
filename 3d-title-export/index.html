🎬 Recording Instructions

Current size: 800x300px

How to record:

  • Mac: Use QuickTime Player → File → New Screen Recording → Select this area
  • Windows: Use OBS Studio or ScreenToGif
  • Web tools: Use ScreenToGif.com or Giphy Capture

Tips:

  • Record for ~4-5 seconds for a smooth loop
  • Remove green screen using video editor or ezgif.com
  • Green background = chroma key for easy removal
